# Pogoshooter

Мобильный аренный шутер на пого-палках. Герой всё время прыгает и не может остановиться, пушка стреляет сама. Ты управляешь только прыжками: зажал палец — пружина сжимается и копит силу, отпустил — прыжок в сторону пальца. Прыгнул врагу на голову — стомп: враг уничтожен, тебя подбрасывает вверх, а серия стомпов без приземления умножает очки.

Сейчас: режим выживания с бесконечными волнами, два типа врагов (ходуны на платформах и летуны, которые с 3-й волны стреляют), сердечки-аптечки, рекорд, звук и вибрация.

## Скачать на Android

Открой репозиторий с телефона → **Releases** справа → последняя сборка → скачай `pogoshooter.apk` и установи. Android попросит разрешить установку из этого источника — разреши.

Каждая загрузка изменений в репозиторий запускает новую сборку (вкладка **Actions**, 5–8 минут). Новая версия ставится поверх старой, рекорд сохраняется.

## Структура

```
src/config.ts   весь баланс: прыжки, оружие, очки, волны, враги, расположение платформ
src/game.ts     правила игры без привязки к экрану
src/render.ts   отрисовка (Canvas 2D), поле 600×900 масштабируется под экран
src/audio.ts    звуки (генерируются кодом) и вибрация
src/main.ts     экраны, управление, игровой цикл
tools/make_icon.py   рисует иконку и заставку в assets/
```

Почти всё, что хочется подкрутить, лежит в `src/config.ts`.

## Запуск на компьютере

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откроется адрес вида `http://192.168.x.x:5173` — его можно открыть и на телефоне в той же Wi-Fi сети. На компьютере: пробел — заряд, ← → или A/D — направление, Esc — пауза.

## Публикация в магазинах

Сборки из Releases подписаны тестовым ключом из `tools/android/pogo-debug.keystore` — он открыт, годится только для тестов. Перед выпуском в Google Play или RuStore:

1. Поменяй `appId` в `capacitor.config.ts` на свой (после первой публикации сменить нельзя).
2. Создай собственный ключ подписи и храни его в секрете (не в репозитории).
3. Собери подписанный `.aab` (Android Studio → Build → Generate Signed App Bundle).
